# 画面設計書：ログイン・新規登録画面

本書は、ミニマリスト業務管理システム「Worknity（フェーズ1）」における「ログイン・新規登録画面」のレイアウト, UI要素, 画面遷移, およびインタラクション仕様を定義する。

ソーシャルログイン（Google, LINE, Microsoft, Yahoo! JAPAN）、パスキー（生体認証）、および従来のパスワード認証を美しく統合し、ユーザーに「圧倒的な簡単さ」と「高いセキュリティ」を提供する新体験のUI/UXを設計する。

※初期コストを完全0円に抑えるため、Apple IDログインはフェーズ1では除外する。

---

## 1. 画面概要

* **画面名：** ログイン・新規登録画面
* **アクセスURL：** `https://app.worknity.jp/login` (新規登録も同URLに統合)
* **目的：** 
  * 既存ユーザーのログイン（ソーシャル / パスキー / パスワード）
  * 新規ユーザーの最速アカウント作成（ソーシャル / パスキー / パスワード）
* **対象ユーザー：** すべてのユーザー（`admin` ロールおよび `staff` ロール）

## 4. 画面仕様・インタラクション（新体験フロー）

### 4.1. ソーシャルログイン/登録フロー（最速：ワンタップ）
1. ユーザーがいずれかのソーシャルログインボタン（Google / LINE / Microsoft / Yahoo! JAPAN）を押す。
2. バックエンドへリダイレクトし、各プラットフォームの認証画面を表示。
3. 認証成功後、バックエンドは連携されたメールアドレスを取得。
   * **既存ユーザーの場合：** 即座にJWTを発行し、メインの在庫管理画面へ遷移。
   * **新規ユーザーの場合：**
     * 自動的に `companies`（企業レコード）と `users`（ロール: admin）を作成。
     * フロントエンド側で「ウェルカム！会社名（屋号）を入力してください」という1つの入力欄を持つモーダルをオーバーレイ表示。
     * 入力して保存すると、そのまま業務を開始できる。

### 4.2. パスキー（顔・指紋認証）フロー（メール ＋ ワンタップ）
1. ユーザーが「メールアドレス」を入力。
2. `[ パスキーでサインイン ]` ボタンを押す。
3. ブラウザ標準の生体認証（Windows Hello / Face ID / Touch ID）のポップアップが起動。
4. **認証成功時：** パスワード入力なしで即座にログインが完了し、在庫管理画面へ遷移。
5. **認証資格情報がない場合：** 「このデバイスにはパスキーが登録されていません。」とエラー案内を表示。

### 4.3. 従来のパスワードログインフロー（フォールバック）
1. ユーザーが「メールアドレス」と「パスワード」を入力。
2. `[ パスワードでログイン ]` ボタンを押す。
3. バックエンドでパスワードハッシュを検証し、成功すればログイン。

## 5. 新規登録（サインアップ）時のパスキー登録体験
メールアドレスとパスワードで**新規にアカウントを作成した直後**、システムはユーザーに以下の新体験ポップアップを提示する。

> 💡 **次回からパスワード不要でログインしませんか？**
>
> このデバイスの顔認証や指紋認証（パスキー）を登録すると、次回からパスワードの入力なしで安全に1秒ログインできます。
>
> `[ パスキーを登録する（推奨） ]`   `[ あとで ]`

* ユーザーが `[ パスキーを登録する ]` を選ぶと、ブラウザの鍵登録API（WebAuthn）が走り、その場で生体情報をデバイスに紐づける。これにより、次回からの面倒な入力を完全に排除する。
