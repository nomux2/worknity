# バックエンド＆データベース開発ルール (Backend & Database Rules)

LaravelによるAPIおよびMySQL/MariaDBデータベースの開発における、セキュリティ、整合性、パフォーマンスを担保するためのルールを定義します。

---

## 1. マルチテナントの隔離とデータガード（最優先事項）
* **ルールの要旨**: 別の会社（テナント）のデータへの漏洩を「プログラムレベル」で完全に防止する。
* **具体的アクション**:
  1. `users` や `stocks` など、テナント（`companies`）に紐づくすべてのモデルには、Laravel Eloquent の **グローバルスコープ** を実装し、すべてのクエリに `WHERE company_id = ?` が自動適用されるようにすること。
  2. グローバルスコープを一時的に解除する `withoutGlobalScopes` は、テナント横断的なバッチ処理などの例外を除き、通常のAPI処理内では原則使用禁止とする。
  3. テナント間でのクエリ漏れ防止およびパフォーマンス向上のため、テナント依存の全テーブルで `company_id` を先頭に配置した複合インデックス（例: `(company_id, id)` または `(company_id, code)`）を必ず設定する。

## 2. 他テナント存在の隠蔽 (404 Not Found)
* **ルールの要旨**: 悪意あるユーザーが他テナントのIDを総当たりで探る行為を防ぐため、データが存在しない場合と他テナントのデータを指定された場合を区別させない。
* **具体的アクション**:
  1. `company_id` が一致しない他テナントのデータ（ID）に対してリクエストがあった場合、`403 Forbidden` ではなく **`404 Not Found`** を返却する。
  2. これにより、そのIDのリソースが「存在しない」のか「他人のもの」なのかを外部から推測できないようにする。

## 3. 在庫更新時のトランザクションと悲観的ロック
* **ルールの要旨**: レースコンディション（同時実行による数量のズレ）を防止し、データの整合性を100%保つ。
* **具体的アクション**:
  1. 在庫の「入庫」「出庫」「棚卸」の処理時には、必ず `DB::transaction()` 内で処理を実行する。
  2. 対象となる在庫レコードを取得する際、必ず **`lockForUpdate()`** (悲観的ロック: `SELECT ... FOR UPDATE`) を使用して取得し、更新が完了するまで他プロセスによる割り込み・上書きを防ぐ。
  3. 出庫処理時には `新数量 = 現数量 - 入力数量` が `0` 未満になる場合、トランザクション内で例外（ValidationException等）をスローし、ロールバックを実行してエラーを返却する。

## 4. テーブル設計と JSON型（`attributes`）の運用
* **ルールの要旨**: 業態ごとの個別要件（賞味期限、ロット番号、サイズ等）に対して、安易にデータベースのカラムを追加しない。
* **具体的アクション**:
  1. `stocks` テーブル等の物理カラムを安易に追加しない。業態固有・一時的な拡張項目は `stocks.attributes`（JSON型カラム）を利用して吸収する。
  2. JSON型内の特定キーに対するインデックスや検索が必要になった場合は、生成カラム（Generated Columns）または Laravel の JSONパスインデックスを定義し、パフォーマンスを確保する。

## 5. 入力バリデーションとエラーレスポンスの統一
* **ルールの要旨**: APIの信頼性と保守性を高めるため、フロントエンドに返却するエラー構造を統一する。
* **具体的アクション**:
  1. すべてのAPIリクエストは FormRequest を用いてバリデーションを強制する。コントローラー内で `request()->all()` を直接処理しない。
  2. バリデーションエラー時は HTTPステータスコード `422 Unprocessable Entity` を返し、Laravel標準の validation errors 形式（`{ "message": "...", "errors": { "field": [...] } }`）で返却する。
  3. エラーログ出力時には、パスワード、クレジットカード番号、個人情報（PII）などの機密情報がマスクされるよう `config/logging.php` またはフィルタを適切に設定する。
